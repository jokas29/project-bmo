# Vision

Project BMO busca crear un compañero de IA personal que tenga continuidad de identidad independientemente del dispositivo desde el que se utilice.

BMO no debe sentirse como una ventana de chat genérica.

Debe sentirse como un personaje que vive contigo digitalmente.

## Experiencia deseada

BMO podrá:

- conversar por iniciativa propia;
- recordar intereses y experiencias;
- sacar temas de conversación;
- hacer preguntas relevantes;
- reaccionar a lo que ocurre alrededor;
- mostrar emociones simuladas mediante expresiones;
- ayudar a completar tareas reales;
- utilizar herramientas del ordenador;
- acompañar al usuario mientras trabaja o se entretiene.

## BMO para Mac

La primera versión completa vivirá en macOS.

Tendrá:

- personaje mediante sprites;
- ventana flotante;
- texto;
- voz;
- micrófono;
- memoria;
- personalidad;
- cámara;
- visión de pantalla;
- percepción contextual;
- herramientas de macOS;
- acceso opcional a Internet;
- iniciativa.

## Visión ambiental

BMO podrá utilizar la cámara del Mac con permiso.

La visión debe estar pensada para obtener contexto, no para vigilar.

Ejemplos:

- detectar que el usuario volvió;
- reconocer objetos relevantes;
- observar cambios en el entorno;
- utilizar algo visible para iniciar una conversación.

Las imágenes no deben almacenarse permanentemente por defecto.

En el futuro podrá existir una capa llamada Ambient Perception que convierta sensores en eventos semánticos como:

- user_entered
- user_left
- user_sat_down
- user_waved
- object_appeared

## Futuro móvil

Después de macOS se desarrollará Android.

Android será otro cuerpo del mismo BMO, compartiendo:

- identidad;
- personalidad;
- recuerdos;
- conversaciones;
- lógica.

## Futuro físico

Finalmente BMO tendrá un cuerpo físico impreso en 3D.

Posibles componentes:

- pantalla;
- cámara;
- micrófonos;
- parlante;
- botones;
- sensores;
- batería;
- computadora embebida;
- motores o servos opcionales.

El objetivo es que no exista un BMO diferente por plataforma.

Debe existir un único BMO con varios cuerpos.
