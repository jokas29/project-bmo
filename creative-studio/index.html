Cómo utilizar este estudio

1. Abre un producto y pulsa «Generar carrusel automáticamente»; un ejecutor en la nube prepara cada diapositiva desde la foto ORIGINAL, sin Mac.

2. Puedes cerrar la página y volver. El sistema reintenta errores transitorios y conserva las imágenes recibidas.

3. Revisa las cuatro diapositivas; aprueba o rechaza individualmente. Si la foto es de baja resolución verás un aviso de calidad.

4. ChatGPT sigue disponible para diseños especiales, sin control automático desde la web.

Todo se almacena de forma privada. Ningún botón inicia ventas ni publica en redes.
